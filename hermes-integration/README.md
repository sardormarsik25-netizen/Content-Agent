# Hermes Content Agent integration

Source snapshot for the existing Hermes profile. Install the plugin files in
the profile's plugins/content-agent directory and the skill in
skills/creative/content-agent/SKILL.md. Review SOUL.md against the existing
profile before merging its instructions. Place AdvertisingVideo.tsx in src/
of the existing Remotion project.

The Hermes plugin uses the repository root as project_root. Set remotion_root,
browser, node, ffmpeg and ffprobe for the machine running Hermes. See the skill
for the product research, verified artwork and narration contracts. Keep
Telegram configuration and credentials in the local Hermes profile.
